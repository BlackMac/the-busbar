## REVIEW FLAGS
1. **Self-reference in the Lead.** The lead story is about a device built with Claude Code (Opus 5); this newsletter is written by an AI agent from the same model family. A one-line disclosure is included in the lead body. A human should decide whether that disclosure is sufficient, whether it should be more prominent, or whether the conflict warrants demoting the story. The editorial defence for running it: it is a Tier A source (Panbo), it is genuinely the week's most interesting DC/marine story, and the copy leads with the caveats (unregistered manufacturer code, uncertified, not waterproof, 550 nits) rather than the capability.
2. **Sources cited from outside the pool** (per AGENT_BRIEF §4, flagged rather than dropped):
   - `theca.org.uk` — Cruising Association, primary source for the LFP guidance. **Recommend adding to tier_b.**
   - `marineindustrynews.co.uk` — trade press. **Recommend adding to tier_b.**
   - `nmea.org` — the standards body itself. **Recommend adding to tier_c** alongside abycinc.org.
   - `actisense.com` — manufacturer explainer used for the certification argument in the Background. Vendor-authored; used for a claim that is not contested and is corroborated by nmea.org.
   - `velitcamping.com` — manufacturer product page for a Product Radar item.
   - `victronenergy.com/meters-and-sensors/...` — same domain as the pooled Victron blog feed; treated as in-pool.
3. **Airstream #26V401 is a catch-up, not a scoop.** The campaign number is *lower* than every other recall in the MaxxAir group, so Airstream filed before Tiffin/Grand Design/Winnebago/Forest River and we missed it in July. This is stated plainly in the item. The in-window hook is the 21 August notification date. A human may reasonably decide a missed filing shouldn't be presented as this week's recall.
   - **Sourcing caveat — verify before publication.** Every fact in this item (campaign number 26V401, 303 units, model years, the 21 August notification date) comes from **RV trade-press aggregation via WebSearch, not from a primary source**. `nhtsa.gov/recalls` returned HTTP 403 to WebFetch this run, so the campaign page was never read directly. The `source_url` in the edition points at `nhtsa.gov/recalls?nhtsaId=26V401`, which is the correct canonical URL but was **not itself fetched or verified**. This matters more than usual: the 21 August notification date is the *only* thing placing this item inside the edition window, so if that date is wrong the item should not run at all. Recommend a human loads the NHTSA page before publishing. Next run should route recall verification through `data.transportation.gov/resource/6axg-epim.csv` (see Broken sources).
4. **The ~1,379-unit MaxxAir total is our own arithmetic** (425 Tiffin + 448 Grand Design + 134 Winnebago + 69 Forest River + 303 Airstream). Neither NHTSA nor MaxxAir publishes a cross-builder total. Labelled as ours in the text, as with the previous 1,076 figure.
5. **FarOutRide date is "last updated," not published.** The Isotemp page is a maintained guide; it entered our RSS feed 22 August. The measured consumption figures are the *same* ones we published on 2026-07-27 — the item is deliberately re-angled onto the engine-coolant heat exchanger, which was not covered in July, and the figures are cited back to that edition rather than presented as new. If a human judges this still too close to the July lead, drop News 3; the edition stands at three stories with Victron at 33%, still under cap.
6. **VM-3P5A pricing is not published** by Victron. Recorded as "Not published" rather than estimated.
7. **Velit V3 continuous current draw is not published** by the manufacturer, and no independent test exists. Called out in the Product Radar editorial line as the missing number rather than filled with a guess. The 10,000 BTU figure is the 12V model's, per the manufacturer page.
8. **Manufacturer code 2046** is reported as Stein describes it in his own article. We have not independently verified who, if anyone, holds that code in NMEA's register.
9. **Alliance RV #26V324 catch-up candidate.** Lithium-specific electrical defect (heating pad not validated for lithium), 2,785 units — larger than any single MaxxAir campaign, and absent from our tracking. Too old for this edition. Suggest a human decides whether to run it as a catch-up item next week.
